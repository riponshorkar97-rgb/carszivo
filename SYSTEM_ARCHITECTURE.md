# Carszivo System Architecture

## Platform Structure

Carszivo consists of:

- Android Mobile App
- Responsive Website
- Backend Server
- Database System
- Cloud Storage

## System Flow

Mobile App / Website
↓
Backend API
↓
Database
↓
Cloud Storage

## Main Services

- User Service
- Car Listing Service
- Search Service
- Chat Service
- Notification Service
- Admin Service

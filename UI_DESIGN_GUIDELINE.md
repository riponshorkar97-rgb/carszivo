# Carszivo UI Design Guideline

## Design Goal
Create a premium, modern and easy-to-use luxury car marketplace experience.

## Design Principles

- Clean interface
- Premium automotive feeling
- Fast navigation
- Mobile friendly
- User trust focused

## Main Design Areas

### Home Screen
- Featured luxury cars
- Search bar
- Categories
- Recommended listings

### Car Details
- Large images
- Vehicle information
- Seller information
- Contact options

### Seller Experience
- Simple listing upload
- Clear forms
- Easy management

## UI Rules

- Consistent spacing
- Clear typography
- Reusable components
